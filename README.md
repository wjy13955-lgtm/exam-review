# 上岸轨迹

根据 Codex 制作的公考备考平台。当前是本地优先的备考驾驶舱，管理考试目标、每日任务、外部题库练习、错题和模考进度。

## 使用方法

直接双击 `index.html` 即可使用，无需安装。数据保存在当前浏览器中，请定期从“设置”页导出备份。

## 安装到手机桌面

项目已支持 PWA。部署到 HTTPS 网站后：

- Android：使用 Chrome 打开，点击页面底部的“安装”。
- iPhone：使用 Safari 打开，点击“分享”→“添加到主屏幕”。

安装后可像普通 App 一样从桌面启动，并可在首次联网加载后离线使用。数据仍保存在当前设备的浏览器空间中，换机或清理浏览器数据前请先导出备份。

## 分享方法

将整个文件夹部署到任意静态网站服务即可分享。每位访问者的数据相互独立，不会上传到服务器。
