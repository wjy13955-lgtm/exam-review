# MVP 与里程碑

## MVP 定义

第一版小程序只要完成一个闭环：

> 设定目标 → 自动生成计划 → 记录练习/错题/模考 → 首页看到进度和到期复盘 → 手动备份数据

只要这个闭环顺，就算 MVP 成立。

## MVP 必须有

- 总览页：考试倒计时、今日完成率、今日任务、今日到期复盘
- 计划页：周计划/月计划、任务完成状态
- 练习页：练习结果录入、最近记录
- 复盘页：拍照/上传错题、知识点、错因、正确思路、遗忘曲线复盘
- 复盘页：成语词义积累/辨析、易混词、语境例句、遗忘曲线复盘
- 模考页：行测/申论成绩录入、目标差距
- 设置页：目标设置、导出备份、恢复备份、清空数据

## 暂不做

- 登录
- 支付
- 云同步
- 自动识别题干
- AI 自动总结
- 复杂图表
- 社交分享裂变
