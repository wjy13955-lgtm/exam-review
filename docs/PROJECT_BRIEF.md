# 上岸轨迹｜项目说明

## 项目定位

上岸轨迹是一个面向个人备考的公务员考试计划与复盘工具。当前阶段优先服务个人自用，不接微信支付，不接云同步，先把“记录—执行—复盘—调整”的闭环打磨顺。

## 当前产品形态

- 网页个人版：用于快速预览和本地使用
- 微信小程序个人版：用于后续导入微信开发者工具、真机预览和提交审核

## 核心用户

正在准备国考/省考，希望用手机记录备考目标、每日计划、练习结果、错题复盘和模考成绩的人。

## 核心场景

1. 设定目标：考试日期、目标地区、行测/申论目标分数、五大模块正确率与完成时间。
2. 执行计划：查看周计划/月计划，完成后打勾。
3. 记录练习：把外部题库 App 的练习结果录入，包括题量、正确率、用时。
4. 错题复盘：拍照/上传错题图片，记录错误知识点，按遗忘曲线复盘。
5. 成语词义积累：积累言语理解里的成语/实词、易混词、辨析点、语境例句，并按遗忘曲线复盘。
6. 模考分析：录入行测/申论成绩，观察距离目标分数的差距。
7. 本地备份：通过导出/恢复保存个人数据。

## 当前边界

当前不做：

- 微信支付
- 会员系统
- 云同步
- 自动 OCR/AI 总结
- 课程售卖
- 题库内容复制

后续可以考虑：

- 云函数接 OCR/AI，自动识别题干和错误知识点
- 订阅消息提醒复盘
- 多设备云同步
- 学习报告导出
