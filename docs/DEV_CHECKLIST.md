# 开发前检查清单

每次继续开发前，先过一遍这张清单。

## 1. 先确认本次目标

本次只做一件主任务，例如：

- 优化总览 UI
- 改错题复盘流程
- 增加模考分析字段
- 准备小程序上线材料

不要同时改太多功能，避免出问题时不好定位。

## 2. 判断是否属于 MVP

如果功能不服务下面这个闭环，就先放后面：

> 目标 → 计划 → 练习 → 复盘 → 模考 → 进度

优先级：

1. 能让你每天用起来
2. 能减少手动记录成本
3. 能帮助发现薄弱模块
4. 能帮助按时复盘

## 3. 文件位置

- 网页原型：根目录 `index.html`、`styles.css`、`app.js`
- 小程序项目：`wechat-miniprogram-personal`
- 小程序页面：`wechat-miniprogram-personal/pages`
- 项目文档：`docs`
- 预览图：`微信小程序个人版-预览.svg`

## 4. 改动后必须检查

- JS 语法检查是否通过
- 小程序配置 JSON 是否有效
- 页面是否有明显中文文案错误
- 是否误加了支付/会员/云同步入口
- 是否复制了题库原题内容
- 是否会导致本地数据丢失

## 5. 打包规则

打包给别人前，优先打包整个小程序目录：

`wechat-miniprogram-personal`

压缩包命名建议：

`上岸轨迹-微信小程序个人版-功能名-日期.zip`

## 6. Git 建议

当前目录出现 `.git` 痕迹但不是有效仓库。正式继续开发前建议重新确认是否要初始化 Git。

如果决定启用 Git，建议第一次提交内容：

- 当前小程序项目
- 项目文档
- README

提交信息：

`init personal miniprogram MVP`
