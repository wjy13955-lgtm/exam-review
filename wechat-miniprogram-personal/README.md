# 上岸轨迹｜微信小程序个人版

这是从当前网页原型迁移出来的微信小程序个人版。

## 当前定位

- 个人自用
- 不接微信支付
- 不接云同步
- 数据保存在当前微信本机缓存
- 支持手动导出/恢复备份

## 已包含页面

- 总览：倒计时、目标分数、今日任务、五大模块目标
- 计划：周计划、月计划、任务完成状态
- 练习：记录模块、题量、正确率、用时和复盘
- 复盘：记录错题索引、错误原因、正确思路
- 复盘增强：支持拍照/上传错题图片，手动补充题干文字和错误知识点
- 选择题复现：支持整题原文、A/B/C/D 选项、你的答案、正确答案，复盘时隐藏答案重新作答
- 成语词义：支持积累成语/实词、易混词、词义、辨析要点、语境和例句
- 遗忘曲线：按当天、第 1 天、第 3 天、第 7 天、第 15 天、第 30 天提醒复盘
- 复盘自测：到期后先隐藏答案，用户主动回忆，再选择「没想起 / 模糊 / 掌握」
- 模考：记录行测/申论成绩，观察目标差距
- 设置：调整目标、导出备份、恢复备份、重置数据

## 如何打开

1. 安装并打开「微信开发者工具」
2. 选择「导入项目」
3. 项目目录选择本文件夹：`wechat-miniprogram-personal`
4. AppID 可先选择测试号/游客模式；后续有正式个人小程序 AppID 后再替换
5. 点击「编译」预览

## 上线前还需要

- 注册个人主体小程序
- 在微信开发者工具里填写正式 AppID
- 真机预览检查
- 补齐隐私政策/用户协议说明
- 根据微信审核要求提交审核

## 重要提醒

个人版数据只保存在当前手机/微信环境里。换手机、清缓存、卸载微信都可能导致数据丢失，建议阶段性在「设置」页导出备份。

## 关于 OCR/AI

当前版本已经预留「拍照/上传错题图片」和「题干文字」字段，但不调用外部 OCR/AI 服务。这样可以保持个人版轻量、无服务器、无密钥泄露风险。

后续如果要自动识别题干、自动总结知识点，建议通过云函数或自有后端中转 OCR/AI 接口，不要把接口密钥放在小程序前端。
